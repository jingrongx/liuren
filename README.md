# 六壬占卜

一个基于传统中国占卜术的Web应用，提供简单易用的界面，帮助用户进行时间吉凶预测。

## 功能特点

- **小六壬占卜**：传统的时间吉凶预测
- **大六壬排盘**：三式之首，天地人三才之道
- **AI 解读功能**：智能分析占卜结果，提供通俗易懂的解读
- **公历/农历转换**：自动显示农历日期
- **四柱显示**：大六壬排盘结果包含四柱信息
- **时辰选择**：支持选择具体时辰或使用当前时间
- **详细的卦象信息**：显示完整的推算过程和结果
- **三天时辰吉凶速查**：快速查看近期时辰吉凶
- **卦象对照表和时辰对照表**：方便参考和学习

## 最新功能

- 支持用户输入具体问题和个人信息

- 天地盘显示

## Web版本使用

### 在线访问
本项目已配置为可直接部署到Vercel上。

### 本地开发

1. 安装依赖：
   ```bash
   npm install
   ```

2. 运行开发服务器：
   ```bash
   npm run dev
   ```

3. 构建生产版本：
   ```bash
   npm run build
   ```

## 部署到Vercel

### 方法1：使用Vercel CLI

1. 全局安装Vercel CLI：
   ```bash
   npm install -g vercel
   ```

2. 登录Vercel：
   ```bash
   vercel login
   ```

3. 部署项目：
   ```bash
   vercel
   ```

### 方法2：使用GitHub集成

1. 将项目推送到GitHub仓库
2. 访问 [Vercel](https://vercel.com) 并登录
3. 点击 "New Project"
4. 选择你的GitHub仓库
5. 点击 "Deploy"

项目会自动检测到这是一个Vite项目并完成部署。

## 使用说明

### 小六壬占卜
1. 选择日期：点击日期选择器选择想要占卜的日期
2. 选择时辰：从下拉菜单选择具体时辰，或使用"当前"自动获取
3. 查看结果：页面会显示详细的占卜结果，包括：
   - 公历日期和农历日期
   - 时辰信息
   - 卦象结果和描述
   - 五行属性
   - 完整的推算过程

### 大六壬排盘
1. 选择日期：点击日期选择器选择想要排盘的日期
2. 选择时辰：从下拉菜单选择具体时辰，或使用"当前"自动获取
3. 查看结果：页面会显示详细的排盘结果，包括：
   - 天地盘
   - 四课三传
   - 类神取法
   - 天将排列
   - 四柱信息
   - 详细的课体分析

### AI 解读
1. 点击"AI 解读"按钮
2. 输入个人信息（选填）：性别、出生日期
3. 输入具体问题（选填）：明确您想要咨询的事情
4. 点击"开始 AI 解读"
5. 查看 AI 解读结果
6. 可点击"复制解读"按钮复制完整解读内容

## 技术栈

- **前端**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS
- **移动端**：Capacitor
- **农历转换**：lunar-javascript
- **AI 集成**：DeepSeek API
- **部署**：Vercel
- **CI/CD**：GitHub Actions

## 卦象系统

### 小六壬卦象
程序包含9个基本卦象：

1. 大安：大吉，诸事顺利（震卦，属木）
2. 留连：小凶，事情拖延（巽卦，属木）
3. 速喜：中吉，快速成功（离卦，属火）
4. 赤口：大凶，口舌是非（兑卦，属金）
5. 小吉：小吉，平稳顺利（坎卦，属水）
6. 空亡：大凶，诸事不顺（中卦，属土）
7. 病符：小凶，健康不佳（坤卦，属土）
8. 桃花：中吉，感情运势（艮卦，属土）
9. 天德：大吉，贵人相助（乾卦，属金）

### 大六壬系统
- 天地盘：月将加时起天盘
- 四课：日干日支各取两课
- 三传：初传、中传、末传
- 类神：根据占卜事项取用神
- 天将：十二天将临位
