**相生**：木生火，火生土，土生金，金生水，水生木

**关系判断**：给定五行A和五行B：

- A生B → "生"
- A克B → "克"
- B生A → "被生"
- B克A → "被克"
- A=B → "比"

### 2.2 天盘排法

**规则**：月将加时——将月将放在地盘时辰位置上，其余顺时针排满。

**算法**：

```
天盘[i] = DI_ZHI[(月将索引 + (i - 时辰索引) + 12) % 12]
```

其中 `i` 是地盘位置索引（0=子, 1=丑, ..., 11=亥）。

**验证**：

- 天盘\[时辰索引] = 月将地支 ✅
- 天盘\[时辰索引+1] = 月将地支的下一个地支 ✅

### 2.3 地盘排法

地盘固定不变：子丑寅卯辰巳午未申酉戌亥，顺时针排列。

**布局方向**：子在下方（南），午在上方（北），卯在左方（东），酉在右方（西），顺时针排列。

### 2.4 伏吟与返吟

**伏吟**：天盘与地盘完全相同（天盘\[i] === 地盘\[i] 对所有 i）

**返吟**：天盘与地盘对冲（天盘\[i] === 地盘\[(i+6)%12] 对所有 i）

## 三、四课

### 3.1 四课计算

| 课名  | 上神           | 下神    | 说明   |
| --- | ------------ | ----- | ---- |
| 第一课 | 天盘\[日干寄宫索引]  | 日干寄宫  | 日干阳神 |
| 第二课 | 天盘\[第一课上神索引] | 第一课上神 | 日干阴神 |
| 第三课 | 天盘\[日支索引]    | 日支    | 日支阳神 |
| 第四课 | 天盘\[第三课上神索引] | 第三课上神 | 日支阴神 |

### 3.2 四课关系判断

根据上神与下神的五行关系判断：

- 上克下：上神五行克下神五行
- 下贼上：下神五行克上神五行
- 上生下：上神五行生下神五行
- 下生上：下神五行生上神五行
- 比和：上神五行与下神五行相同

### 3.3 四课不全的情况

当四课中出现重复课时，称为"四课不全"（实际只有三课或更少）：

1. **第一课上神 = 日支** → 第二课与第三课相同
2. **第三课上神 = 日干寄宫** → 第四课与第一课相同
3. **日干寄宫 = 日支**（干支同位）→ 第一课与第三课相同、第二课与第四课相同（四课两备，用八专法）

## 四、三传（九宗门）

### 4.0 九宗门总流程

```
开始
 ↓
是否伏吟？ → 是 → 伏吟法
 ↓ 否
是否返吟？ → 是 → 返吟法
 ↓ 否
四课有克贼？
 ├─ 一克 → 贼克法
 ├─ 多克 → 比用法 → 涉害法
 └─ 无克
      ↓
     有遥克？ → 是 → 遥克法
      ↓ 否
     干支同位？ → 是 → 八专法
      ↓ 否
     四课不全？ → 是 → 别责法
      ↓ 否
     昴星法
```

**关键顺序**：

1. 伏吟/返吟优先判断
2. 有克贼时：贼克 → 比用 → 涉害
3. 无克贼时：遥克 → 八专 → 别责 → 昴星
4. **别责法在昴星法之前**（四课不全用别责，四课全备用昴星）

### 4.1 第一门：贼克法

**适用条件**：四课中只有一个克贼。

**规则**：

- 先看下贼上（重审课）：取上神为初传
- 再看上克下（元首课）：取上神为初传
- 下贼上优先于上克下

**中末传**：中传=初传之上神，末传=中传之上神

### 4.2 第二门：比用法

**适用条件**：四课中有多个克贼。

**规则**：取与日干同阴阳的上神为初传。

- 阳日取阳支上神，阴日取阴支上神
- 下贼上优先于上克下
- 若无同阴阳者，取异阴阳者

**中末传**：同贼克法

### 4.3 第三门：涉害法

**适用条件**：比用法仍无法决定（多个克贼与日干同阴阳）。

**规则**：

1. 收集所有克贼的课
2. 取与日干同阴阳者为候选
3. 计算涉害深度：从上神在地盘位置顺数到下神位置，上神五行克地盘五行的次数
4. 取涉害最深者为初传
5. 若深度相同，按孟仲季优先级决定（孟>仲>季，看下神位置）
   - 孟位 → 见机课
   - 仲位 → 察微课
   - 季位 → 缠绵课

**涉害深度计算**：

```
从上神位置开始，顺时针数到下神位置，
每经过一个地盘位置，若上神五行克该位置地支五行，深度+1
```

**中末传**：同贼克法

### 4.4 第四门：遥克法

**适用条件**：四课无克贼。

**规则**：

1. **蒿矢**：四课上神克日干（寄宫五行）→ 取该上神为初传
2. **弹射**：日干克四课上神 → 取该上神为初传
3. 蒿矢优先于弹射

**多遥克处理**：若有多个蒿矢或弹射，应按比用法原则取与日干同阴阳者。

**中末传**：同贼克法

### 4.5 第五门：八专法

**适用条件**：日干寄宫与日支相同（干支同位），四课两备，无克贼。

**口诀**：刚日用第一课上神顺数三位，柔日用第四课上神逆数三位为初传，中末俱用干上神。

**规则**：

1. 确认日干寄宫 = 日支
2. 刚日（阳日）：从第一课上神顺数3位取初传（含起点本身为第1位）
3. 柔日（阴日）：从第四课上神逆数3位取初传（含起点本身为第1位）
4. 中传 = 干上神（第一课上神）
5. 末传 = 干上神（第一课上神）

**示例**：若第四课上神为巳，柔日逆数3位 → 巳(1)→辰(2)→**卯**(3)，初传为卯。

**注意**：八专法的中末传俱用干上神，不使用通用 fillZhongMo 方法。

### 4.6 第六门：别责法

**适用条件**：四课不全（只有三课），无克贼，无遥克。

**规则**：

1. 取日干之合干（甲己合、乙庚合、丙辛合、丁壬合、戊癸合）
2. 取合干寄宫上天盘为初传
3. 中传 = 初传之上神
4. 末传 = 中传之上神

**四课不全判断**：

- 第一课上神 = 日支 → 第二课与第三课重复
- 第三课上神 = 日干寄宫 → 第四课与第一课重复
- （干支同位的情况已由八专法处理）

### 4.7 第七门：昴星法

**适用条件**：四课全备，无克贼，无遥克。

**规则**：

- **阳日昴星（虎视转蓬）**：
  - 初传 = 酉上天盘（天盘在酉位上的地支）
  - 中传 = 初传之上神（天盘在初传位置上的地支）
  - 末传 = 地盘酉（即"酉"本身）
- **阴日昴星（蛇虎交加）**：
  - 初传 = 地盘酉（即"酉"本身）
  - 中传 = 初传之上神 = 酉上天盘
  - 末传 = 酉上天盘（与中传相同）

**注意**：昴星法的末传不使用通用 fillZhongMo 方法，必须按上述规则设定。

### 4.8 伏吟法

**适用条件**：天盘与地盘完全相同。

**有克伏吟**：

- 初传 = 取克贼的上神
- 中传 = 初传之刑
- 末传 = 中传之刑

**无克伏吟**：

- 阳日（自任课）：初传 = 日干寄宫
- 阴日（自信课）：初传 = 日支
- 中传 = 初传之刑
- 末传 = 中传之刑

**自刑处理**：若初传或中传为自刑地支（辰午酉亥），则取冲代替刑。

### 4.9 返吟法

**适用条件**：天盘与地盘对冲。

**有克返吟**：

- 初传 = 取克贼的上神
- 中传 = 初传之上神
- 末传 = 中传之上神

**无克返吟（无依课）**：

- 初传 = 日支驿马
- 中传 = 初传之冲
- 末传 = 中传之冲（= 初传）

**驿马规则**：

- 申子辰马在寅
- 寅午戌马在申
- 巳酉丑马在亥
- 亥卯未马在巳

## 七、空亡

### 7.1 空亡计算

**规则**：根据日柱干支所在的旬来确定空亡地支。六十甲子分为六旬，每旬空亡两个地支。

**口诀**：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。

**算法**：

1. 找到日干支所在旬的旬首（旬首天干固定为甲）
2. 旬首地支 = (日支序 - 日干序 + 12) % 12
3. 空亡地支 = 旬首地支后退1位和后退2位

| 旬  | 旬首 | 空亡 |
| -- | -- | -- |
| 甲子 | 甲子 | 戌亥 |
| 甲戌 | 甲戌 | 申酉 |
| 甲申 | 甲申 | 午未 |
| 甲午 | 甲午 | 辰巳 |
| 甲辰 | 甲辰 | 寅卯 |
| 甲寅 | 甲寅 | 子丑 |

### 7.2 空亡判断

三传中任一地支落入空亡，则该传"落空亡"，主事情虚而不实、难以落实。

### 7.3 真空与假空

空亡地支需区分真空（死空）与假空（活空）：

- **真空（死空）**：空亡地支在月令处于休囚状态，且不被冲、不被合、非日干禄马，则完全无力
- **假空（活空）**：空亡地支满足以下任一条件，虽空而有气：
  1. 被冲（冲空则实）
  2. 被六合或暗合（合空则实）
  3. 为日干禄神
  4. 为日支驿马
  5. 月令五行生助空亡地支五行（旺相有气）

**判断算法**：

1. 计算空亡地支
2. 检查是否被冲（天盘冲地盘）
3. 检查是否被合（六合、暗合）
4. 检查是否为日干禄神或日支驿马
5. 检查月令五行是否生助空亡地支五行
6. 以上条件均不满足则为真空，满足任一则为假空

## 十一·附四、年命与行年

### 年命（本命）

求测者出生年的地支，即生肖对应的地支。

### 行年

根据年龄推算的地支，代表求测者当年的运势：

- **男命**：从出生年地支起一岁，顺数至当前年龄
- **女命**：从出生年地支起一岁，逆数至当前年龄

**算法**：

```
男命行年 = (出生年地支索引 + 年龄) % 12
女命行年 = (出生年地支索引 - 年龄 + 12 × N) % 12
```

**应用**：年命和行年在四课三传中的位置，可判断求测者与占事的关系。
